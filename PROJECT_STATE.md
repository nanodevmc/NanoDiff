# NanoDiff — Состояние проекта

## Архитектура и стек
- **Продукт:** Универсальный глубокий инспектор архивов и визуализатор диффов без Git.
- **Стек:** Tauri v2 (Rust 2021 Core), TypeScript, React 19, Vite, Tailwind CSS (Liquid Glass + MD3).
- **Стилистика:** Liquid Glass + Material Design 3 + Google Icons, терминальный неон (#070a08, #9bf246).
- **Дистрибуция:** Легковесный нативный Windows NSIS Installer (1.35 МБ) и Portable бинарник (4 МБ) на Рабочем столе.
- **Потребление ресурсов:** < 35 МБ RAM (Windows WebView2 runtime), мгновенный запуск.

## Ключевой реализованный функционал
1. **Рекурсивный VFS:** Потоковое чтение ZIP/JAR/APK/WAR в оперативной памяти без сброса на диск. Поддержка вложенности любой глубины (`archive.zip -> sub.jar -> deep.zip`).
2. **Семантический Diff:** Полный алгоритм Myers Diff с группировкой чанков, подсчётом `+additions` / `-deletions` и строковыми номерами.
3. **Подсветка синтаксиса на 54 языка:** Мгновенная регулярная токенизация ключевых слов, типов, строк, комментариев, операторов без внешних тяжелых WASM рантаймов.
4. **Визуальный Diff изображений:** 3 режима сравнения текстур и спрайтов: «Шторка» (Split Slider), «Наложение» (Onion Skin) и «Рядом» (Side-by-side).
5. **Два режима отображения кода:** Сплит (Split Side-by-Side) и Юнифайд (Unified linear).
6. **Liquid Glass UI:** 8/10 элементов с живыми анимациями (радар дропзоны, сканирующие полосы, парящие неоновые сферы, микроинтеракции кнопок).
7. **Tauri v2 Desktop App:** Чистый нативный бинарник без Electron.
